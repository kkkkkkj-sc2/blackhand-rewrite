# 共生体（3/29）实现与验收

## 玩家操作

- 中立（温和），拼音 `gongshengti`。默认权重 **0**，可在自设中手动添加；修改权重后可进入全体随机、中立随机和中立温和池。
- 首夜点击另一名活人的行动按钮，**立即、不可撤销**地绑定；双方立刻获得身份提示并可交谈。不能选择自己、假死者或另一名共生体，避免互绑闭环。
- 首夜结束仍无宿主：黎明死亡，聚会夜也不豁免。
- 宿主非中立：共生体使用自己的开关（或 `-on` / `-off`），为宿主发动一次当晚整夜无敌，默认关闭。
- 宿主中立：宿主输入 `-symb 楼层号` 指挥额外攻击，单独输入 `-symb` 取消。按投票面板楼层号定位，**不是内部玩家编号**。宿主原有目标与开关不变。
- 护盾和突袭共用每名共生体的一次机会。宿主阵营改变不会补充次数；被限制、监禁或无效目标导致未发动，不扣次数。
- 突袭实际发动就牺牲共生体；目标即使被无敌、次数盾、治疗或保镖挡住，共生体仍死亡。该刀正常受女巫、司机与限制影响，保镖正常拦截并受攻击，不二次杀死已牺牲的共生体。
- 宿主死亡立即连带杀死仍存活的共生体，白天处决同样生效。无宿主死亡、连带死亡与主动牺牲均不受救治或无敌阻止。
- 共生体即使已经死亡，结算时仍复制宿主的最终胜负，不依赖玩家座位先后；包含唐吉诃德后置共享胜利。不会重复记胜败场数。

## 夜聊

- 宿主已有频道：共生体实时继承该频道权限，不改自己的阵营、身份或宿主频道数组；既有频道收到用户指定的加入提示。
- 无频道：建立仅宿主与共生体互通的私聊，不向公共频道泄漏。
- 法官／公告员的公开夜间发言：共生体能发言，公屏只署名「共生体」，不泄漏宿主姓名或借用宿主角色称号。
- 兼容黑手党／三合会／共济会／邪教、感染者双人频道、中立致命同角色频道、间谍窃听与疯子领袖隔离。
- 监禁、狱警私聊、禁言、私密审查频道等原有隔离规则优先，不得通过共生体绕过。

## 维护接线

唯一实现仍在 `work/blackhand/CustomLogic.galaxy`，不加载插件或拼接临时片段。

- 永久状态：`gv_gsHost`、`gv_gsUsed`、`gv_gsSacrificed`；`gf_GSReset` **只在开局**执行。
- 每夜选择：`gf_SKN_3_gongshengti` 清 `gv_gsShield` / `gv_gsStrike`，不补次数、不解绑、不重置结算记账。
- `gf_GSPrepareNight` 位于准备阶段末尾，**早于**女巫／司机／限制处理；突袭结算读取最终 `gv_visitation`。无突袭则访问自己。
- `gf_GSApplyShield` 位于击杀阶段开头，晚于限制、早于攻击；`gf_GSResolveKills` 在常规中立刀段之后处理。
- `gv_nightSequence` 是演出配置，**不是当前是否正在结算**。操作门用 `gv_isNight` 和 `gv_nightProcessingPhase`；夜间文案覆盖 `gv_nightEvents` 结算阶段。
- 死因：`q` 突袭，`r` 未寄宿，`s` 纽带反噬，`t` 主动牺牲；均有验尸官分支。
- `gf_GSKillPlayerDirect` 保留原死亡清理完整函数体；自动包装函数先捕获玩家参数再委托。宿主死亡时先无等待地移除所有依附者，再执行完整尸体／银行／界面清理，避免清理让出线程时出现错误判胜。
- 25 个既有终局逐人循环跳过共生体，循环后独立结算；`gf_DQShareWin` 后再次幂等同步。角色号29不得访问只有21槽的角色首胜数组。
- 探员使用独立「冰冷意识」线索；未犯罪时警长按正常无嫌疑路径，突袭记非法闯入与谋杀。

## 待游戏内验收

1. 普通包自设添加共生体；单人包有五名额外可交互目标。
2. 首夜点选立即互知、开始交谈，已绑定不能换人；未选择时黎明按指定文案死亡。
3. 绑定城镇或黑手党宿主：开启护盾，验证当夜生效、下夜不再有次数；被限制时不消耗。
4. 绑定中立宿主：原行动照常，`-symb` 额外刀独立；无敌／治疗／保镖分别验证，含女巫／司机改向。
5. 分别验证已有阵营频道、新二人频道、感染者频道，以及法官／公告员匿名公开发言，无无关玩家串听。
6. 宿主夜死、白天处决时均立即连带死亡；先死的共生体仍能随最终获胜的宿主结算，胜败场数只增加一次。
