# 额外规则：开局公告（shw314）

## 展示

仅当至少一项额外规则开启时，开局发送一条标题：

> 本局游戏启用了以下额外规则：

随后按转世重生、团伙作案、亡灵小镇的顺序，每个启用项单独发送一条 `「规则名称」：说明`。名称使用黄色 `FFFF00`，说明与额外规则面板保持一致；不显示未开启的项目，也不改面板原有配色。

- **转世重生**：最先死亡的四名玩家会一同以生存者的身份复活，每人初始有 1 份食物。
- **团伙作案**：同名中立致命会加入各自的频道，且胜利条件不再要求存活到最后。
- **亡灵小镇**：死者在死后依然可以发言。

## 接线与边界

- [主脚本](<../work/blackhand/CustomLogic.galaxy>) 的 `gf_XRAnnounce` 读取本局实际生效的 `gv_xrLife` / `gv_xrGang` / `gv_xrDead`；不读取控件、不改开关、阵营、死亡或判胜逻辑。
- 唯一调用位于 `gt_Start_Func` 既有的小丑／处刑者红开关公告循环：取名结束及清空旧聊天之后、欢迎入场提示之前，逐一发送给 `gv_currentPlayers` 中的玩家。原有两条红开关公告及其开关条件保留；不要求局内实际存在对应职业。
- 全关无标题、无条目。标题使用既有提示音，规则条目静音，避免连续多次提示音。
- 沿用 `gf_CBSystemMessage`，因此进入系统消息记录并随聊天框放大；不增加昼夜切换时的重复播报。
- 新文案位于[文案源](<../work/blackhand/strings-shw.txt>)，四个 `XRANN*` 键已加入[打包回读必需键](<../tools/boot2_build.py>)。

## 回归

[公告专项](<../tools/test_extra_rules_announcements.py>) 实际抽取公告函数及原开局接收者循环，执行三项额外规则的全部八种组合、两项红开关的四种组合及不同在场玩家集合；检查标题／条目数量、内容、顺序、接收者、提示音、全关静默以及开关不被改写，并静态检查调用时机、字号入口和打包键。

公告专项通过 128 组场景、16,796 项检查（UBSan/bounds）；[面板回归](<../tools/test_extra_rules_ui.py>) 的三项开关及弹窗层级检查通过。Galaxy lint 1637 函数、0 问题。C++ 抽取测试和源码检查不等同于 SC2 引擎渲染或完整对局实测。
