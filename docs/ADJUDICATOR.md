## 日期与轮次

原生时钟是 **夜 N → 白天 N+1 → 夜 N+1**。不能把待公布名单绑定旧夜号。

- 夜 N 有效选二人，待晨报全部死亡结算后在白天 N+1 筛存活者。
- 二人存活：公布双人；一人存活：只公布单人；零人存活：不耗轮次、下夜可重选。
- 成功公布后夜 N+1 为休息/一次性报复；夜 N+2 才可再选名单。
- 只有有效白天内原生成功处决的实际死者计数；普通夜死、雷击、管理员击杀、律师拦截、天选庇护、演出期间先因其他原因死亡均不算。
- 同一人复活后再被真实处决可重复计数，跨名单可重复选人，无永久历史黑名单。
- 报复不能选择上一夜实际冻结的两名目标（包括晨报前死亡后又复活的人），不是只排除晨报公布的存活者；最终重定向后再次检查。
