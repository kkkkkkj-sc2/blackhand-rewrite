## 2. 共同规则

“中立·过客”是公开职业类别，不是覆盖真实归属的新胜利阵营。

- 转世继承死亡前真实阵营：城镇、黑手党、三合会随队胜负，死亡也可共胜；所有中立归属统一为“存活至游戏结束”。原生/自设过客默认中立存活目标。
- 只共胜，不独立触发胜利，也不能延迟其他角色获胜。判胜及送审人数排除过客；五名非过客加两名过客，常规多数门槛为三票。
- 不能提名、投有罪/无罪票或被提名。隐藏票、聊天命令与界面入口均设资格门，事务员也不能使过客重新有票。
- 职业与楼层公开，公告/面板不公开真实归属，职业名颜色不随归属改变；原阵营夜聊和盟友清单不保留。过客没有调查免疫，警长等调查仍沿用真实阵营口径，不把“未公开”扩成“调查不可得知”。
- 正常受到夜杀、调查、限制、司机交换和女巫控制；没有自带无敌。禁止再次转职/转营，不等于免疫所有白天处决。
- 开局原生过客公告一次；转世先完成全批复活再集中公告：`一位过客{楼层}.{玩家名}来到了城镇，他是个「{职业}」。`
- 转世重生累计前四名真实死者，从五职业不放回抽四种并随机分配；不再初始化为生存者，也不继承食物/旧职业无敌。

## 3. 能力与操作

| 职业 | 能力与操作 |
|---|---|
| 见证者 | 夜间行动按钮选一人，可选自己。统计第一/第二访问槽的独立访客人数，排除本人；同一访客只计一次。夜间访问快照在夜后转换前保存，次日私密反馈。 |
| 信使 | 白天技能按钮打开十五楼层配对面板，选两名不同的存活在场玩家；也可输入 `-pair 楼层 楼层`。允许选择自己，清空取消，关闭保留。当晚建立专属频道，信使随后死亡不取消已定配对。 |
| 傀儡 | 白天技能按钮或 `-puppet` 切换准备状态。公开处决前从已准备且有效的存活傀儡中随机选一人替死；先处理律师/状师与天选者的免死，不递归替死。 |
| 护魂侍 | 夜选他人，成功施加时赠予一次单次攻击次数盾，自身终身限一次；不能自选，被限制/关押或目标无效时不耗次。不是整晚无敌，沿用既有次数盾穿透规则。 |
| 事务员 | 夜选一人，成功后耗一次能力，目标次日提名及有罪/无罪票权固定为三；覆盖更高票权，不叠加。限制/关押或目标无效不耗次，过客始终零票。 |

### 信使隔离边界

- 关系是直接边，不求连通闭包：A-B 和 A-C 并存时，A 的发言 B/C 均可听见，B 的发言 C 听不见。
- 参与者当晚失去原夜聊的发送与接收，不是“原频道照播、另发一份”。次日自动失效；信使死亡后即使立即转世成其他过客职业，当日已施放的有效配对仍保留。
- 普通夜聊、共生体、冤魂、团伙作案、哭泣旁听、帮派牢房旁听和频道耳语都经过隔离门；共生体不继承宿主被替代前的频道，也不会被隐式加入信使配对。
- 关押、私人频道、禁言/屏蔽仍有优先级，不因信使能力绕过这些权限。系统消息与死聊不是原阵营夜聊。

## 4. 实现入口

主逻辑维护于 [CustomLogic.galaxy](../work/blackhand/CustomLogic.galaxy)。

| 范围 | 关键入口 |
|---|---|
| 不变身份/真实归属 | `gv_gkRole` / `gv_gkFaction`、`gf_GKIs`、`gf_GKSetRoleField`、`gf_GKInit` |
| 判胜及共胜 | `gf_GKAliveCount`、`gf_CheckEnd`、`gf_GKWon`、25 个 `ET*Win` 主胜者判据 |
| 批量转世 | `gf_XRLifeNote` 保存真实归属，`gf_XRLifeFlush` 洗牌，`gf_XRTryRebirth` 专用构造，最后逐一公告 |
| 投票 | `gf_BHVoteWeight`、各送审/审判/隐藏票入口、`gf_GKVoteUI` |
| 能力生命周期 | `gf_GKPrepareVisits` → 原交换/限制 → `gf_GKResolveEarly`（夜刀首句）→ 夜后转换 → `gf_GKWitnessSnapshot` → 次日反馈 |
| 公开处决 | `gf_EExecution` 先免死判定，再 `gf_GKSubstitute`，异步演出只传实际死者 |
| 信使聊天 | `gf_GKMailFreeze` / `Window` / `Peer` / `Hidden` / `Intercept` / `Route`；接入两套聊天函数及特殊接收边界 |
| 面板/命令 | `gf_GKNightPanel` / `NightClick`、`gf_GKDayRefresh`、`gf_GKPanelBuild`、`gt_GKCommand_Func`、`gt_GKPanel_Func` |

所有普通职业字段写入经 `gf_GKSetRoleField` 作最终身份兜底。转换成功事务还必须提前排除过客，不能仅拒写角色而留下扣次、公告、清盾或阵营覆写。

- 审计官、新版征募官、邪教成功分支：成功副作用前门控。
- 巫医：只禁止转职，原有救治/消耗和瘟疫清理保留。
- 狸猫：选择、查找和交换入口拒绝过客，避免只改一方。
- 缺刀继任人数排除过客；原生职业/阵营守卫保持，不把继承真实归属误当原生帮派职业。感染者亲子图保留为传承/胜利账本，但私聊资格逐端排除过客，构造时关闭旧私聊开关。
- 失忆者记忆过客走专用中立构造与公开公告，不继承尸体的隐藏归属。
- `-change` / `-stumpify` 拒绝现有过客；管理员由普通角色生成过客时也必须构造快照与公告。
- 伪装者/神偷仍可正常夜杀并取得尸体外观；外观交换不复制过客职业或归属，不因此赋予夜杀免疫。
