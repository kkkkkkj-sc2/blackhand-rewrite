# 男爵 / 泰斗（shw308 起；shw319 白天招募；shw320 调查免疫）

## 行为与入口

- 男爵为黑手党领袖 `2/22`，泰斗为三合会领袖 `5/22`；每晚一刀、固有夜间无敌及调查免疫，可被限制和关押。**未增加首夜限制免疫**，先前该提议已取消。
- 开局在随机槽解算后、优选预占和职业 setup 前，保留领袖，将**己方**其他帮派席替换为随机城镇并真实归城镇；不改变另一帮派。使用有名称、正权重的城镇职业，空权重池回落市民。
- 招募只在**全局首个白天选人，紧接着入夜立即生效**。白天开局对应 `dayNumber=1`；夜晚开局对应 `dayNumber=2`，开局第一夜不能选人或提前耗掉机会。`gf_BRFirstDay` 提供统一编号。
- 两角色独立使用互斥的二／三／四人档，默认三人；名单与夜间击杀目标互相独立。选择时只检验公开的存活、非假死、他人及楼层条件，不反馈隐藏阵营。中立或帮派目标可以留在待定名单，但提交时不合格就落空。
- 招募不产生访问；出刀接管既有帮派 hitman/target，继续标准单刀链，沿用交换、限制、救治和保镖处理。
- 疯子模仿22时可以使用相同的假招募面板和指令反馈，但不能获得真正的夜间无敌、调查免疫、帮派刀或阵营转换资格。

## 白天面板与入夜提交（shw319）

- 首个白天点击通用“技能”按钮，打开仅本人可见的 `900×470` 招募弹层，按楼层排列三列五行玩家按钮。内部绑定玩家编号，不把楼层错当编号；按钮只显示公开楼层和姓名，不显示身份或招募资格。
- 点击玩家选中／取消，已选项用圆点和绿色标识；人数计数使用实际能力开关上限。关闭及审判开始只隐藏面板，不清名单；首个白天内可重新打开修改。“清空名单”清四个槽。白天不直接转换阵营。
- 保留 `-recruit 1 2 3` 兼容入口（四人档可加第四楼层），仅在同一个白天窗口有效。无参数清空；新名单原子替换；无效、重复、自选或超限不会部分写入。
- `gf_BRCanSelect` 统一检查首昼编号、白天行动开放、非夜晚、非昼终、非审判、存活／在场／非假死／未关押，以及尚未冻结和提交。弹层每次点击、指令每次提交都重验权限；看不到面板的玩家不能借共用控件写入名单。
- 白天技能按钮在 `gt_DaySequence_Func` 标准复位后及 `gf_ASStartVote` 恢复投票时启用，后者也覆盖普通审判恢复及 `gf_TXResumeDay`。`gf_ASEndActions`、`gf_ASStopVote` 和入夜入口统一隐藏弹层；不改变投票或审判状态。
- `auto_gf_NightTransition_TriggerFunc` 关闭白天行动和关押点击事件后，在 `gv_isNight=true`、入夜重置、`gf_RSConversions`、职业 setup 和夜聊开放之前，依次关闭面板、`gf_BRFreezeRecruit`、`gf_BRResolveRecruit`。不提前打开夜聊，也不放宽阵营转换 API。
- `Freeze` 只在离开首个白天时冻结真正领袖的存活、在场、非假死及未关押资格；不把**上一夜**残留的限制或死亡标记当作此次白天资格。`Resolve` 按提交时目标的真实城镇阵营和存活状态逐人转换，保留职业和原能力状态；完成后一次性关闭机会并清四槽，空名单合法。
- 已移除旧 `DayTransition` 的冻结／招募调用。招募不再等待当夜死亡或急救复活；随后该夜的限制、关押或死亡不会撤销已经完成的入帮，但仍照常影响夜间行动。若领袖在白天死亡、目标提交时死亡或不属城镇，则相应招募不成功。
- 入帮只改变阵营，不额外重跑 NativeInit 或清理职业资源；之后照常进入该职业的夜间 setup。男爵招入黑手党，泰斗招入三合会；本人收到既有私密入帮提示，无额外公屏转换播报。
- **调查时序随之改变**：生效的那个夜晚，警长按入帮后的阵营调查；间谍等对外调查伪装、陷害、调查免疫及警长开关仍照原规则。此前“招募当晚仍按城镇，天亮才转阵营”的结论仅适用于 shw318 及以前的旧流程。

## 招募成员的继任

- [主脚本](<../work/blackhand/CustomLogic.galaxy>) 的 `gf_RSConversions` 每次入夜在行动面板和职业准备之前处理，本轮招募提交先于它执行。活着的男爵／泰斗本身有刀，招募不会强制把其成员立刻改为党徒或暴徒。
- 招募成员按真实阵营计入存活帮派人数；若之后己方缺少可以杀人的角色，在原有入夜继任时机成为党徒 `2/1`／暴徒 `5/1`。成功者立即占用一个刀口，避免同轮全体转职；原生领袖、参谋／管家优先，弃子／死士仍最后垫底。
- `gf_BHConvertedSuccession` 仍使用原规则的 `alive` 资格、刀口计数和参谋／管家升领袖保留门，不额外加假死、限制或关押字段门；真正假死者已不在存活组。
- 真正改职业才清阵营覆盖、把永久基础票权归一、清次数盾和两个旧行动目标，再刷新角色卡、统计及私密继任提示；不重置开局身份、次数和冷却。单纯入帮不做这些清理，狱警的已选关押目标等职业状态不会被转换操作误清。
- [继任专项](<../tools/test_baron_succession.py>) 和[律师继任回归](<../tools/test_lawyer_conversions.py>) 保持原生继任规则覆盖，不是 SC2 完整对局实测。
