# 恶棍（3/28）

中立（邪恶），拼音 `egun`，铜褐色 `C47A44`，默认权重 0，无额外开关、无自身夜间无敌。

## 能力与交互

- 每晚选择另一名活人，正常登门。目标按钮悬停为“使其负伤”；选中后隐藏目标按钮，自己的座位显示灰色“取消”按钮。点击自己取消、恢复原目标按钮；改选其他活人恢复旧目标并隐藏新目标。自己的按钮仅用于取消，不是访问自己。交换、控制、限制和关押沿用现有访问体系。
- 成功施伤只记案底 **4：破坏治安**。不记非法闯入或谋杀，不设凶手归因。
- 每次新伤在获得的当晚都不会致死，从下一晚起生效；可同时存在多名负伤者。
- 后续任何真实访客可触发旧伤，包含第二访问槽和当夜随后死亡的访客。负伤者访问自己、所有恶棍的访问均豁免。
- 医生与巫医的有效治疗清除伤势，包括与恶棍同晚登门；治疗不被伤势逻辑消耗，仍可救治当晚其他可救治攻击。
- 夜间无敌或剩余免死机会阻止施伤，并让受害者认出恶棍；已有伤势在获得此类防护时清除。伤势逻辑不消耗防护次数。
- 保镖访问可触发旧伤，但不拦截施伤，不与恶棍互砍。
- 普通死亡优先，伤势不得覆盖已有死因、描述及归因。旧伤死亡在系命传播之前处理。
- “你听见痛苦的呻吟声...”沿用教父枪声的红色 `FF0000` + `ModLeftSize16`；系统/角色提示默认也使用 `ModLeftSize16`，由原替换表随聊天框变为 20/24 号，还原回 16。玩家聊天/私聊原样式不改。

## 判胜

- 恶棍必须存活，且存活城镇为零；其条件并入全部 25 个结算入口的实际胜者分支。
- 不抢夺黑手党、三合会、邪教或中立致命阵营的正常判胜。
- 只剩恶棍及可共胜的中立、且城镇与敌对致命阵营均为零时，以结算码 **28** 收束。
- 末期阵营力量比较计入恶棍的中立邪恶票。城镇仍有至少两人时，保留互访触发伤势的机会。
- 仅剩一名城镇和若干恶棍时，没有能触发伤势的访客，判城镇胜以避免死锁；恶棍不获胜。
- 唐吉诃德的中立共胜识别结算码 28。新增角色不访问仅有 21 槽的角色首胜银行数组。

## 接线与资源

- `gf_EGReset` 仅在初始化清空持久状态。
- `gf_EGPrepareNight` 在 `gf_TTApplyProtect` 后、所有杀戮前快照免疫、有效治疗和双槽访问，并统一施伤、清伤。
- `gf_EGResolveNight` 在普通杀戮后、系命传播前，根据快照结算旧伤；即使恶棍全灭也运行。
- `gf_EGWoundDeath` 使用死因码 `g`，验尸官分支同步接入；不另行检查或消耗治疗、免死次数。
- 夜间演出提示为“你听见痛苦的呻吟声...”，接男女平民死亡音效；私密提示沿用可放大的消息入口。
- 探员属保镖的“不断在住所间移动”组，候选文案及所有历史变体均含恶棍。
- 胜利图 `WinEgun.dds` 由原创 PNG 生成，732×376、24 位 BGR，登记在打包器的 `DDS_ASSETS` 并回读校验。
